# 관리자 안내문 — 예울마루 STAY 패키지 객실 선택

예매자에게 링크를 문자로 보내면, 예매자가 폰에서 **휴대폰 뒷 4자리 확인 → 객실(더블/트윈) 선택**까지 합니다.
**숙박일은 고객이 고르지 않습니다.** 예매한 공연 날짜가 곧 숙박일이고, 명단에 미리 넣어 둡니다.

---

## 0. 준비 — 한 번만

**1) 배포한다**
Cloudflare Pages에 붙이고 R2 바인딩(이름 `R2`)과 `BOOK_PIN`(관리자 비번)을 넣습니다.
자세한 절차는 `README.md` 5번. 배포하면 나오는 주소가 **곧 고객에게 보낼 링크**입니다.
현재 실서비스 주소: **https://staypackage.pages.dev**

**2) 비번을 저장한다**
저장소 루트에 `.booking.json` 파일을 만듭니다. (git에 안 올라갑니다)

```json
{ "pin": "BOOK_PIN에 넣은 값" }
```

주소는 실서비스가 기본값이라 비번만 있으면 됩니다. 다른 주소를 볼 때만 `"url"` 을 추가합니다.
이걸 넣어야 아래 명령들이 돕니다.

**3) 공연·날짜·수량을 확인한다**

```bash
node tools/rooms.mjs
```

기본값은 홍보물 그대로입니다. 다르면 `/admin.html` 에서 고칩니다.

| 공연 | 구분 | 숙박일(체크인) | 더블 | 트윈 |
|---|:---:|---|---:|---:|
| 음반발매기념 〈조재혁 피아노 리사이틀〉 | `a` | 2026. 9. 12(토) | 5 | 5 |
| 국립현대무용단 〈트리플 빌〉 | `b` | 2026. 10. 14(수) | 8 | 7 |
| 다비드 바뱅 & 아드리앙 몽도 〈피아노 피아노〉 | `c` | 2026. 10. 27(화) | 8 | 7 |

## 1. 명단 등록 — 문자 보내기 전에 반드시

**명단에 없는 번호는 링크를 열어도 못 들어옵니다.** 그래서 문자보다 명단이 먼저입니다.

한 줄에 한 명씩, `뒷4자리, 공연구분, 이름` 순서로 적습니다. 이름은 없어도 됩니다.

```
1234, a, 홍길동
5678, b, 김철수
9012, c
```

- 첫 칸 = 휴대폰 번호 **뒷 4자리**
- 둘째 칸 = **어느 공연을 예매했는가** (`a` · `b` · `c`) → 이게 그 사람의 숙박일이 됩니다
- 셋째 칸 = 이름

엑셀에서 세 칸을 그대로 복사해 붙여넣어도 됩니다. 저장 방법은 둘 중 하나:

```bash
node tools/rooms.mjs roster 명단.txt      # 파일로
```

또는 `/admin.html` 의 **명단 등록** 칸에 붙여넣고 저장.

> **이 명령은 기존 명단을 통째로 교체합니다.** 처음 한 번 넣을 때만 쓰세요.
> 뒷 4자리가 겹치면 뒤엣사람을 버리고 어느 번호가 겹쳤는지 알려줍니다 — 그때 연락 주세요.

### 한 명씩 고치기 — 평소에는 이걸 쓰세요

나머지 명단은 건드리지 않습니다. **클로드코드에 그냥 말씀하셔도 됩니다** —
*"4650 황세웅 조재혁으로 추가해줘"* 하면 아래를 대신 돌립니다.

```bash
node tools/rooms.mjs add 4650 a 황세웅   # 추가 (같은 번호면 수정)
node tools/rooms.mjs move 4650 c         # 공연(=숙박일)만 바꾸기
node tools/rooms.mjs rm 4650             # 명단에서 빼기
```

휴대폰 번호를 통째로 주셔도 됩니다(`010-3021-4650`) — **뒷 4자리만** 씁니다.
이미 객실을 고른 사람의 공연을 바꾸면 숙박일이 달라지므로, 그때는 `cancel` 도 해야 다시 고를 수 있습니다(명령이 그때 알려줍니다).

## 3. 현황 확인 — 클로드코드에 그냥 물어보세요

**"객실 몇 개 남았어?"** 하고 물으면 바로 표로 보여줍니다. 관리자 화면을 열 필요 없습니다.
직접 치려면:

```bash
node tools/rooms.mjs              # 남은 객실
node tools/rooms.mjs list         # 선택 완료한 사람 목록
node tools/rooms.mjs pending      # 아직 안 고른 사람
node tools/rooms.mjs all          # 위 셋 한 번에
node tools/rooms.mjs who 1234     # 한 사람 조회
node tools/rooms.mjs csv          # 엑셀에 붙여넣을 표
```

```
■ 남은 객실  (남은 / 전체)

  숙박일     공연                     더블   트윈     합계
  9/12(토)   조재혁 피아노 리사이틀  4 / 5  5 / 5   9 / 10
  10/14(수)  트리플 빌               8 / 8  6 / 7  14 / 15
  10/27(화)  피아노 피아노           7 / 8  7 / 7  14 / 15

  전체 37 / 40실 남음 · 선택 완료 3건 · 명단 5명 · 미선택 2명
```

## 4. 상황별 대응

### 객실을 바꿔 달라고 연락이 왔을 때

선택을 취소하면 그 자리는 **즉시 다시 열리고**, 그 사람은 링크를 다시 눌러 고를 수 있습니다.

```bash
node tools/rooms.mjs cancel 1234
```

그리고 이렇게 안내하면 됩니다 — *"취소해 드렸습니다. 받으셨던 링크를 다시 열어 원하시는 객실로 선택해 주세요."*
바꾸려는 객실이 이미 마감이면 취소하기 전에 먼저 확인하세요(`node tools/rooms.mjs`). 취소만 하고 못 고르는 일이 생깁니다.

### "명단에 없다고 나온다" 고 할 때

그 사람 번호가 명단에 빠졌거나 뒷 4자리가 다릅니다. 명단에 줄을 추가하고 **전체를 다시 저장**하면 바로 들어갑니다.

### "마감이라 못 고른다" 고 할 때

그 공연의 그 객실이 다 찼습니다. `node tools/rooms.mjs` 로 남은 종류를 확인해 안내하거나,
`/admin.html` 에서 그 공연의 수량을 늘립니다(숙박 시설과 협의된 경우에만).

### 아직 안 고른 사람 재안내

```bash
node tools/rooms.mjs pending
```

명단에 있는데 아직 안 고른 사람만 나옵니다. 이 사람들에게 링크를 다시 보내세요.

### 최종 명단 넘기기

```bash
node tools/rooms.mjs csv
```

탭으로 구분되어 나오니 엑셀에 그대로 붙여넣으면 됩니다.
(`/admin.html` 의 **표 복사(엑셀)** 버튼도 같은 일을 합니다)

## 5. 알아둘 것

- **숙박일은 고객이 못 고릅니다.** 명단의 공연 구분이 정합니다. 날짜가 틀렸다면 명단의 구분을 고치세요.
- **같은 사람은 한 번만 고릅니다.** 이미 고른 사람이 링크를 다시 열면 **자기가 고른 내역만** 보입니다.
- **마지막 한 자리를 두 사람이 동시에 눌러도 안 겹칩니다.** 먼저 누른 한 명만 성공하고, 다른 한 명은 "방금 마감됐어요"를 봅니다.
- **취소하면 그 자리는 즉시 다시 열립니다.** 남은 수량은 저장해 두는 게 아니라 매번 다시 세기 때문입니다.
- **관리자 비번(`BOOK_PIN`)이 없으면 관리자 기능은 통째로 잠깁니다.** 아무나 명단을 갈아엎지 못하게 한 것입니다.
- **문자 발송은 이 프로그램 밖입니다.** 링크만 만들어 드립니다.
- 고객 화면에는 숙박 시설 사정에 따라 **디럭스로 상향될 수 있다**(예매 순서 기준)고 안내되어 있습니다.
